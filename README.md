# 📸 Photobooth Studio (เว็บแอปพลิเคชันโฟโต้บูธเชื่อมต่อกล้องและเครื่องปริ้น)

เว็บแอปพลิเคชันตู้ถ่ายรูปโฟโต้บูธ (Photobooth Web Application) พัฒนาขึ้นโดยอ้างอิงฟังก์ชันและความสามารถจากโครงการโอเพนซอร์สชั้นนำ [photobooth-app.org](https://photobooth-app.org) รองรับการเชื่อมต่อกล้องเว็บแคม/DSLR และสั่งพิมพ์ภาพออกเครื่องพิมพ์ (CUPS / AirPrint) พร้อมระบบแชร์รูปผ่าน QR Code ให้แขกในงานดาวน์โหลดเข้ามือถือได้ทันที

---

## ✨ จุดเด่นและฟีเจอร์หลัก (Features)

### 1. 📷 การเชื่อมต่อกล้อง (Camera Integration)
* รองรับกล้องของคอมพิวเตอร์ (เช่น กล้อง FaceTime HD ของ MacBook), กล้อง USB Webcam ภายนอก, และกล้อง DSLR/Mirrorless ผ่านการ์ดแคปเจอร์ (HDMI Capture Card / Cam Link)
* พรีวิวภาพแบบเรียลไทม์ (Live Video Preview) แบบกลับด้านภาพเหมือนกระจก (Mirror mode) หรือภาพจริง
* นับเวลาถอยหลัง (Countdown Timer 3s / 5s / 8s) ด้วยตัวเลขขนาดใหญ่ แอนิเมชัน และเสียงสัญญาณ Beep
* แสงแฟลชสีขาวเต็มหน้าจอ (Screen Flash Effect) พร้อมเสียงชัตเตอร์กล้องถ่ายรูปจริง (Mechanical Shutter Sound) สร้างด้วย Web Audio API (ไม่ต้องโหลดไฟล์เสียงเพิ่ม)
* รองรับการกดปุ่ม **Spacebar** บนคีย์บอร์ด หรือต่อปุ่มกดภายนอก (Arcade Button / Bluetooth Pedal) เพื่อสั่งถ่ายรูป

### 2. 🎞️ เทมเพลตและเลย์เอาต์ (Photo Strip Layouts)
* **4 ช็อต สไตล์ตู้เกาหลี (4-Shot Strip)**: แถบโฟโต้บูธแนวตั้งยอดนิยม (สัดส่วน 2x6 นิ้ว)
* **2 แถวคู่ตัดครึ่ง 4x6" (Dual Cut Strip)**: **ฟีเจอร์ระดับมืออาชีพ!** สั่งพิมพ์ 2 แถวคู่ลงบนกระดาษ 4x6 นิ้ว แผ่นเดียว พร้อมเส้นประสำหรับตัดแบ่งแจกแขกได้ 2 คนทันที
* **3 ช็อต คลาสสิก (3-Shot Classic)**: แถบ 3 รูปสไตล์คลาสสิก
* **ตาราง 2x2 (Grid 2x2)**: รวม 4 ช็อตรูปแบบตารางสี่เหลี่ยม
* **1 รูปเดี่ยว (Single Photo)**: ภาพถ่ายเดี่ยวพร้อมกรอบตกแต่ง

### 3. 🎨 ฟิลเตอร์และการตกแต่ง (Filters & Branding)
* เลือกฟิลเตอร์ได้ทันที:
  * **Original**: ภาพสีสดใสธรรมชาติ
  * **B&W**: ขาวดำคลาสสิก คอนทราสต์สวยงาม
  * **Sepia**: โทนวินเทจ อบอุ่น
  * **Warm**: โทนแสงแดดอบอุ่น Golden hour
  * **Cool**: โทนเย็น สะอาดตา สไตล์โมเดิร์น
  * **Glamour**: ผิวเนียน สว่าง มีออร่า
  * **Vivid**: สีสันสดใส คมชัด
* ปรับแต่งชื่องาน วันที่ และสถานที่ (Branding Header/Footer)
* ปรับเปลี่ยนสีกรอบ (ขาว, ดำมืด, ชมพูพาสเทล, ครีมมินิมอล, ม่วงลาเวนเดอร์, เขียวมิ้นต์)

### 4. 🖨️ การเชื่อมต่อเครื่องปริ้น (Direct Printer Integration)
* เชื่อมต่อกับระบบการพิมพ์ของระบบปฏิบัติการ (macOS / Linux CUPS Subsystem) ผ่านคำสั่ง `lp` และ `lpstat`
* ตรวจจับเครื่องพิมพ์ในระบบอัตโนมัติ (เช่น `HP Ink Tank Wireless 410 series` ที่ติดตั้งอยู่ในเครื่อง)
* **สั่งพิมพ์ทันที (Direct Print)**: ส่งงานพิมพ์ตรงไปยังเครื่องปริ้นโดยไม่ต้องกดผ่าน Dialog ซ้ำซ้อน
* เลือกจำนวนชุดที่ต้องการพิมพ์ (Copies: 1, 2, 3...)
* รองรับตัวเลือกพิมพ์ผ่าน Browser Dialog (AirPrint) เผื่อในกรณีสั่งพิมพ์จากอุปกรณ์พกพา
* ระบบพิมพ์ทดสอบ (Test Print) เพื่อเช็คการทำงานของเครื่องพิมพ์

### 5. 📱 สแกน QR Code ดาวน์โหลดเข้ามือถือ (Wi-Fi Mobile Download)
* หลังจากถ่ายรูปเสร็จ จะมีปุ่มแสดง **QR Code** บนหน้าจอ
* ตรวจจับหมายเลข IP เครือข่ายในวง Wi-Fi เดียวกันอัตโนมัติ (เช่น `http://172.28.121.125:3001/share/...`)
* แขกในงานใช้สมาร์ทโฟนสแกน QR Code เพื่อเปิดหน้ารูปภาพและกดบันทึกลงโทรศัพท์ได้ทันที!

### 6. 🖼️ คลังรูปภาพ (Gallery) และการตั้งค่า (Admin Settings)
* ดูประวัติรูปถ่ายทั้งหมดของงาน พร้อมสั่งพิมพ์ซ้ำ (Reprint) หรือดาวน์โหลดได้ตลอดเวลา
* หน้าต่างตั้งค่าระบบ (Settings): เลือกกล้อง, เลือกเครื่องปริ้น, ขนาดกระดาษ, เปิด/ปิดเสียง, เปิด/ปิดระบบ Auto-Print

## 🚀 วิธีเปิดใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
* Node.js (เวอร์ชัน 18 ขึ้นไป แนะนำ v20 หรือ v24)
* ระบบปฏิบัติการ macOS หรือ Linux (รองรับ CUPS สำหรับการพิมพ์โดยตรง)

### คำสั่งเริ่มต้นใช้งาน (Run Application)

1. เปิด Terminal ในโฟลเดอร์โครงการ:
```bash
cd /Users/octagram/Photobooth-app
```

2. เริ่มต้นรันเซิร์ฟเวอร์และเปิดเว็บแอป:
```bash
npm start
```

3. เปิดเว็บเบราว์เซอร์ (แนะนำ Google Chrome, Safari หรือ Microsoft Edge) เข้าไปที่:
* **บนเครื่องคอมพิวเตอร์ที่ต่อกล้อง**: [http://localhost:3001](http://localhost:3001)
* **บนมือถือหรือแท็บเล็ตในวง Wi-Fi เดียวกัน**: `http://<IP_เครื่องคอมพิวเตอร์>:3001` (เช่น `http://172.28.121.125:3001`)

*(หากต้องการรันในโหมดพัฒนา Development พร้อม Vite Hot-Reload สามารถใช้คำสั่ง `npm run dev`)*

## ⚙️ การตั้งค่าเครื่องปริ้นและกล้องเพิ่มเติม

1. **การตรวจสอบสถานะเครื่องพิมพ์ผ่าน Terminal**:
   ```bash
   lpstat -p -d
   ```
   ระบบจะแสดงชื่อเครื่องพิมพ์เริ่มต้น เช่น `HP_Ink_Tank_Wireless_410_series`

2. **การตั้งค่าขนาดกระดาษ**:
   สามารถเลือกได้จากเมนู **Settings (รูปฟันเฟือง)** ในแอป:
   * `4x6` นิ้ว (สำหรับกระดาษโฟโต้การ์ดทั่วไป)
   * `iso_a4_210x297mm` (สำหรับกระดาษ A4)
   * `Custom.2x6in` (สำหรับเครื่องพิมพ์โฟโต้บูธเฉพาะทาง)

3. **โหมด Kiosk เต็มหน้าจอ (Fullscreen)**:
   กดไอคอนขยายหน้าจอที่มุมขวาบน หรือกดปุ่ม `F11` (บน Windows) / `Ctrl + Cmd + F` (บน Mac) เพื่อเปิดโหมดตู้ Photobooth เต็มหน้าจอ
