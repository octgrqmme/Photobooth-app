# เว็บสาธารณะบน Vercel

โฟลเดอร์นี้เป็น static site สำหรับประชาสัมพันธ์งานเท่านั้น ให้เลือกโฟลเดอร์นี้เป็น Root Directory ของ Vercel project หรือ deploy จากโฟลเดอร์นี้โดยตรง

กล้อง Canon, Live View, ระบบคิว, ฐานข้อมูลภาพ และ CUPS/เครื่องพิมพ์ยังทำงานบน Mac ผ่าน `npm run dev` (`http://localhost:8000`) เท่านั้น ภาพสำเร็จรูปใหม่จะถูกส่งไป private Blob หลังประกอบภาพ ส่วนภาพเก่าส่งเมื่อเจ้าหน้าที่กดสร้าง QR ในแกลเลอรี ลิงก์ดาวน์โหลดออนไลน์มีอายุ 1 ชั่วโมง และสร้างใหม่ได้โดยเจ้าหน้าที่ ไม่มีแกลเลอรีสาธารณะหรือ API ควบคุมอุปกรณ์บน Vercel

อย่าเพิ่ม `media/`, `database/`, `userdata/`, `config/` หรือไฟล์ QR ของภาพจริงเข้าโฟลเดอร์นี้ ไฟล์ `./.env.local` เก็บ Blob token สำหรับ Mac เท่านั้นและถูก gitignore ห้ามส่งไฟล์นี้ให้ผู้เข้าร่วม โทเคน QR เป็น bearer link: ผู้ที่มีลิงก์จะเปิดภาพได้จนหมดอายุ
