# คู่มือปฏิบัติงานเจ้าหน้าที่ (Operator Runbook)

คู่มือนี้ครอบคลุมขั้นตอนการเปิดงาน ดูแลบูธระหว่างงาน การแก้ปัญหาหน้างาน และขั้นตอนปิดงานสำหรับระบบ Photobooth Platform (รองรับทั้ง Event Mode, Self-Service Kiosk และ Managed Kiosk ฟรีโดยไม่มีระบบชำระเงิน)

---

## 1. ก่อนเปิดงาน / ก่อนเชื่อม Wi-Fi งาน

1. **เปลี่ยนรหัสผ่าน Admin จากค่าเริ่มต้น `0000`:**
   - แก้ `common.admin_password` ใน `config/config.json` (ห้ามใช้ `0000` เมื่อออกงานจริง)
2. **ติดตั้งไฟล์ Customizations ล่าสุด:**
   ```bash
   bash scripts/install_customizations.sh
   ```
3. **ตรวจความพร้อมของระบบ (Preflight Check):**
   ```bash
   bash scripts/preflight.sh
   ```
   ตรวจสอบให้แน่ใจว่า `0 fail(s)` และเช็กกล้อง Canon + เครื่องพิมพ์ CUPS ในหน้า `/control-center.html` (แท็บ **ภาพรวม & Preflight**)
4. **สร้าง Snapshot สำรองก่อนเริ่มงาน:**
   ```bash
   bash scripts/release_snapshot.sh --label pre-event
   ```

---

## 2. หน้าจอใช้งานหลัก

- **จอถ่าย / เจ้าหน้าที่หลัก:** `http://127.0.0.1:8000/`
- **ศูนย์ควบคุมกลาง (Control Center):** `http://127.0.0.1:8000/control-center.html`
- **ตู้ถ่ายเอง (Self-Service Kiosk):** `http://127.0.0.1:8000/kiosk.html`
  - ปลดล็อกเมนูเจ้าหน้าที่บน Kiosk: แตะมุมซ้ายบน (`⚙`) **5 ครั้งติดกัน** แล้วใส่รหัส `admin_password`
- **โต๊ะพิมพ์ (Print Desk):** `http://127.0.0.1:8000/print-desk.html`
- **จอคิว (Queue Board):** `http://127.0.0.1:8000/queue-board.html`

> **การเข้าถึง Control Center จากเครื่องอื่นใน LAN (iPad/Notebook เจ้าหน้าที่):**  
> เครื่องอื่นที่ไม่ใช่ `localhost` ต้องใส่ header `X-Admin-Token` (บันทึกไว้ในช่อง Admin Token ด้านบนของ `/control-center.html`) ซึ่งระบบจะเปิดให้ใช้เฉพาะเมื่อ `common.admin_password` ไม่ใช่ `0000` แล้วเท่านั้น

## 3. การจัดการเหตุขัดข้องหน้างาน

### 3.1 งานพิมพ์ขึ้นสถานะ `unknown` (ไม่แน่ใจว่ากระดาษออกหรือไม่)
- **ห้ามกดสั่งพิมพ์ซ้ำทันทีโดยไม่ตรวจถาดกระดาษ** (ระบบจะไม่พิมพ์ซ้ำอัตโนมัติ)
- ไปที่แท็บ **คิว & งานพิมพ์** ใน `/control-center.html` หรือหน้าหลัก:
  - หากกระดาษออกมาครบแล้ว → กด **`ยืนยันว่าพิมพ์ออกแล้ว`**
  - หากกระดาษไม่ออก/กระดาษติดและต้องการยกเลิก → กด **`ยกเลิกงานนี้`** จากนั้นค่อยสั่งพิมพ์ใหม่แบบตรวจสอบได้

### 3.2 กล้องหลุด / ค้างระหว่างถ่าย
- ตรวจสาย USB ของกล้อง Canon หลีกเลี่ยงการเปิด Live View ค้างไว้พร้อมกับแอปอื่น (เช่น EOS Utility / Image Capture)
- Kiosk จะแสดงข้อความให้ลองถ่ายใหม่หรือติดต่อเจ้าหน้าที่โดยไม่ลบข้อมูลคิวเดิม

### 3.3 อินเทอร์เน็ตหลุด (Offline Event)
- การถ่ายภาพ คิว พิมพ์ภาพ และเปิดแกลเลอรีส่วนตัวบน Wi-Fi ท้องถิ่น (`/gallery.html?token=...`) **ทำงานต่อได้ตามปกติ**
- รายการ Cloud QR จะถูกเก็บไว้ใน **Durable Outbox** (`userdata/photobooth_platform.sqlite`) และลองอัปโหลดซ้ำอัตโนมัติพร้อมปุ่ม **`ส่งใหม่ทันที`** ในแท็บ **Cloud & ลิงก์แชร์**

### 3.4 Watchdog ตรวจสุขภาพระบบ
```bash
bash scripts/watchdog.sh --url http://127.0.0.1:8000 --once
```
สคริปต์จะไม่สั่งรีสตาร์ตอัตโนมัติหากยังมีงานพิมพ์สถานะ `unknown` คิวที่กำลังใช้งาน หรือกล้องกำลังถ่ายภาพ เพื่อป้องกันการทำลายงานที่ค้างอยู่

## 4. การปิดงาน ลบข้อมูลตามอายุ และ Rollback

1. **ปิดรับคิว/เซสชันชั่วคราว:** กดปุ่ม **`สลับสถานะเปิด/ปิดรับคิว`** ใน Control Center (Kiosk จะแสดงหน้าปิดรับโดยไม่ลบคิวเดิม)
2. **ส่งออกรายงานสถิติ:** แท็บ **วิเคราะห์ข้อมูล** → กด **`ดาวน์โหลดรายงาน CSV`**
3. **ตรวจอายุภาพและยกเลิก Token หมดอายุ (Retention):**
   - แท็บ **อีเวนต์ & นโยบาย** → กด **`ตรวจรายการครบอายุ (Dry-run)`** ก่อนเสมอ แล้วค่อยกดลบ (ภาพที่ยังค้างพิมพ์จะถูกคุ้มครองอัตโนมัติ)
4. **สำรอง/ย้อนกลับข้อมูล (Backup & Rollback):**
   ```bash
   bash scripts/restore.sh "<path-to-backup-dir>" --dry-run
   bash scripts/restore.sh "<path-to-backup-dir>"
   ```
   (ดูรายละเอียดเพิ่มเติมใน [backup-restore.md](file:///Users/octagram/Persenol/Coding/Photobooth-app/docs/backup-restore.md))
